# GothicII — czcionka w nagłówkach

Plik: `GothicII.woff2` (podzbiór web), `GothicII.ttf` (pełny)

Źródło: https://github.com/Patrix9999/Gothic-2-Font
Release: 1.0 — `GothicII.ttf` (wektorowa konwersja oryginalnej bitmapowej
czcionki z gry Gothic II, bez dodatku Night of the Raven).

Repozytorium nie zawiera pliku licencji. Czcionka jest fanowską konwersją
grafiki UI z gry Gothic II (Piranha Bytes / THQ Nordic). Użycie wyłącznie
w niekomercyjnym, fanowskim przewodniku po instalacji gry na Linuksie,
z przypisaniem autorstwa konwersji (Patrix9999). Wszystkie prawa do oryginalnej
czcionki i znaków towarowych Gothic należą do Piranha Bytes / THQ Nordic.

Podzbiór web (woff2) wygenerowano z `GothicII.ttf` przy użyciu fontTools
(Latin + Latin-Ext + polskie znaki + typografia podstawowa).

# Cormorant Garamond + Fira Code — czcionki treści (lokalne)
