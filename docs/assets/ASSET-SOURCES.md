# Presentation assets

The article text remains in the original Markdown files, unchanged.

- `images/khorinis.png`: unmodified screenshot of Khorinis in Gothic II,
  from Try/OpenGothic (`scr0.png`), commit `05486efb9259f96c592b878ad822c8c9bbd465bf`.
  Source: https://github.com/Try/OpenGothic/blob/05486efb9259f96c592b878ad822c8c9bbd465bf/scr0.png
  Original game visuals belong to their respective Gothic rights holders.
  Used as decorative scenery for this noncommercial fan guide.
- `fonts/GothicII.woff2` and `.ttf`: supplied in the user's prototype;
  Patrix9999's vector conversion of Gothic II's original bitmap font.
  Source: https://github.com/Patrix9999/Gothic-2-Font
  See `fonts/FONT-LICENSE.md` for provenance. The upstream project does not
  declare a font license; no additional licensing permission is asserted here.
- `fonts/gfonts/*`: Cormorant Garamond and Fira Code from the supplied prototype.
  Complete OFL license texts are included alongside the font files.

No prototype SVGs depicting invented game symbols are used. Interface chevrons,
menu controls, borders and corner details are CSS shapes, not purported game assets.
The palette follows the supplied Night of the Raven cover reference; the background
is an actual game screenshot, not that cover or a generated imitation.
